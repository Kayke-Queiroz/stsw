### Seminário sobre ferramentas de desenvolvimento seguro de aplicações

Cada aluno deverá preparar uma **apresentação de 20 minutos** sobre uma **ferramenta de desenvolvimento seguro de aplicações**, com foco técnico e demonstrativo, conforme orientações abaixo.

---

#### Lista de ferramentas estudadas

* [Trivy](https://trivy.dev/latest/)
* [sqlmap](https://sqlmap.org/)
* [XSStrike](https://github.com/s0md3v/XSStrike)
* [SSRFMap](https://github.com/swisskyrepo/SSRFmap)
* [OWASP Dependency-Check](https://owasp.org/www-project-dependency-check/)
* [SonarQube](http://www.sonarqube.org)

---

#### Entregáveis Obrigatórios

1. **Slides de apresentação no diretório `/workshops/submissions/seu-nome/seu-nome.pdf**, elaborados de acordo com a estrutura mínima recomendada.
1. **Código de exemplo no diretório `/workshops/NN-WWWW/submissions/seu-nome/src`** demonstrando o uso do framework apresentado.
1. **Arquivo `README.md` no diretório `/workshops/NN-WWWW/seu-nome`** com com **instruções claras para execução do exemplo** e um **resumo da ferramenta apresentada**, conforme estrutura sugerida abaixo.
1. Submeter pull request e enviar o link do pull request no ambiente virtual.

---

#### Sugestão de Estrutura para o README de Submissão

O conteúdo a seguir deve estar no arquivo:

```
/workshops/NN-WWWW/submissions/seu-nome/README.md
```

##### Título
> Nome do framework (e versão, se relevante), nome do aluno, data da apresentação.

##### Introdução
- Breve descrição do framework.
- Onde o framework se posiciona na **pirâmide de automação de testes** (unidade, serviço/API, interface).

##### Principais Funcionalidades
- Recursos suportados.
- Tipos de testes possíveis: caixa-preta, caixa-branca, ambos.
- Integrações disponíveis (com JUnit, CI/CD, navegadores, etc).

##### Demonstração
- Descrição breve do exemplo implementado.
- Link para o repositório com instruções para execução do código.

##### Lista de Frameworks Similares
- Ferramentas alternativas que atuam no mesmo nível da pirâmide ou com propósito semelhante.

##### Vantagens e Desvantagens
- Destaques técnicos, maturidade, curva de aprendizado, documentação, performance, etc.

##### Casos de Sucesso
- Empresas ou projetos que utilizam o framework com bons resultados.

##### Conclusão
- Avaliação crítica e recomendações de uso.
- Quando adotar (ou não) o framework apresentado.

##### Instruções para execução do exemplo

#### Critérios de Avaliação
- Clareza e organização da apresentação.
- Qualidade técnica da demonstração.
- Profundidade na análise comparativa.
