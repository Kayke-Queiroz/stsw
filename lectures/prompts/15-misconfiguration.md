## Security Misconfiguration (A05:2021)

### Introdução à Vulnerabilidade Security Misconfiguration 

```
Explique o que é uma vulnerabilidade de Security Misconfiguration, segundo a OWASP.
- Quais são os exemplos mais comuns dessa vulnerabilidade em aplicações web?
- Por que configurações padrão ou inseguras representam um risco de segurança?
- Quais são os impactos possíveis da exploração dessa falha?

- Qual a diferença entre falhas de configuração de software, servidor e framework?
- Como a OWASP classifica a gravidade dessa vulnerabilidade e por que ela está no Top 10?
```

### Exemplos Práticos de Security Misconfiguration

```
Apresente um exemplo de código ou configuração que represente uma falha de Security Misconfiguration.
- O que há de errado na configuração apresentada?
- Como essa falha poderia ser explorada por um atacante?
- Reescreva a configuração de forma segura.

- Simule um cenário onde diretórios sensíveis estão acessíveis sem autenticação.
- O que deve ser verificado para evitar exposição de endpoints administrativos?
```

### Aplicação em Cenários Reais

```
Considere uma empresa que deixa os painéis de administração expostos sem autenticação e com credenciais padrão.
- Quais as consequências reais de uma exploração nesse cenário?

- Elabore um checklist de segurança para configuração de servidores web.

- Analise um caso público real de violação de dados causado por má configuração.
- Quais as lições aprendidas com esse incidente?
```
